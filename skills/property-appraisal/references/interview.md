# The Buyer Interview (one batch)

Asked after research, before synthesis. One message, all questions at once, numbered so the buyer can answer inline. 8-12 questions. Cut anything research already answered and say which ones you cut and why ("permit records show a 2021 roof — skipping that question").

## Phrasing rules

- Reference research facts where possible: "The 2019 listing photos show original oak cabinets — still the case?"
- Offer answer shortcuts: "(rough year is fine)", "(skip any you don't know)".
- Never ask about things the deck doesn't use.
- Close the batch with: "Skip any you don't know. I'll use neutral assumptions and label them."

## The question set

**Q0 (always first): Have you walked the property in person, or are you working from photos and the listing?**
Sets condition-input confidence. Photos-only pushes confidence down per methodology §6.

**Q1. Roof — age and material, best guess?**
**Q2. HVAC — age of the system(s)? Any known issues?**
**Q3. Water heater — age, tank or tankless?**
**Q4. Kitchen — original, partially updated, or fully remodeled? Rough year if updated.**
**Q5. Bathrooms — same scale, per bath if they differ.**
**Q6. Flooring — type and condition in the main living areas.**
**Q7. Known defects — anything on foundation, moisture/drainage, pests, windows, or electrical? Anything the listing discloses or the agent mentioned?**
**Q8. Renovations in the last 10 years — what was done and rough spend, if known.**
**Q9. Lot and location negatives — busy road, power lines, backs to commercial, drainage from neighbors, anything that made you pause on site?**
**Q10. Extras — pool, workshop/outbuilding, whole-home generator, dock, owned solar, fencing condition?**
**Q11 (only if list price context is missing): What's the asking price, and do you have a number in your head?**

## Answer-to-adjustment mapping

All dollar figures below are calibrated to a $250-600K single-family home in a Gulf Coast market and carry a vintage of 2025-Q4. In another region or price tier, scale them and say you did; re-verify replacement costs annually. Scale proportionally for other price tiers (express as % of value where given). Cure costs should be replaced with local quote midpoints when research surfaced them. Everything derived from an "I don't know" is labeled **assumed**; everything from "seller says" is labeled **reported, unverified** and taken at half weight.

| Input | Finding | Adjustment |
|---|---|---|
| Roof | ≤5 yrs, verified | +$3-6K (remaining-life premium vs neutral) |
| | 6-11 yrs, verified | $0 |
| | 12+ yrs verified, **or visible wear at any age** | −(replacement midpoint × age ÷ expected life). Asphalt in a hurricane market: $12-20K replacement, ~17-yr expected life. A verified 14-yr roof → −(16K × 14/17) = −$13K. A 20-yr roof → −$14-18K. Insurance angle: an aging roof also raises premiums in wind states — note it, do not double count. |
| | age unknown | $0, tagged **assumed** (neutral 10-yr). The $0 band is for unknowns and for roofs with real life left, never for a verified aging roof. |
| HVAC | ≤5 yrs | +$2-4K |
| | 6-12 yrs | $0 |
| | 13+ yrs | −$6-12K per system (replacement midpoint prorated) |
| Water heater | 10+ yrs tank | −$1.5-2.5K |
| Kitchen | Full remodel ≤5 yrs | +50-70% of spend if known, else +4-7% of value |
| | Partial update | +1-3% of value |
| | Original, 20+ yrs | −3-6% of value |
| Bathrooms | Remodeled ≤5 yrs | +1-2% of value per bath |

| | Active pest / prior termite w/ repair | −$3-15K est. depending on scope |

**Neutral assumptions when unknown:** roof 10 yrs, HVAC 8 yrs, kitchen/baths consistent with year built and price tier, no defects, no extras. Each assumed item appears on the Condition Adjustments slide tagged "assumed".

**Double-count guard:** if a factor was already adjusted at the comp level (e.g., subject's busy road handled in each comp's location adjustment), do not repeat it here. Each factor lives in exactly one place. State which place in the adjustment note.
